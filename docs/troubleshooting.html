Troubleshooting

Run litecode doctor first. It shows the engine, folders and models.

ProblemCauseFix
engine not foundno llama-serverlitecode setup, or litecode config engine PATH
no model for role 'x'model file missinglitecode setup, or litecode config roles.x FILE.gguf
llama-server exited during startupnot enough RAM, or bad model fileclose programs; use a smaller model; download the file again
First answer is slowmodel loads from disk, prompt is processednormal. Next tasks are faster. Keep models on an SSD if possible
Output is garbage (GGGG...)broken model file or engine bug for that modelcheck the file hash against Hugging Face; try another quant or a newer engine
(model broke protocol, retrying)small model wrote text, not JSONnormal now and then. If constant, use a bigger model with /model quality
litecode command not foundPython scripts folder not on PATHuse python -m litecode.cli, or add the folder to PATH
Commands fail on Windows with WSL errorsbash resolves to the WSL stublitecode uses Git Bash or PowerShell. Install Git for Windows for bash
PC freezes, disk light onRAM is full, Windows swapsuse a smaller model, lower ctx, close the browser
Port in useanother server on 8080litecode config port 8090
MCP server failsmissing npx/uvx, or bad argsrun the server command by hand to see the error
Wrong answers repeata bad example is reused/bad after a bad answer; /forget to clear facts

Logs: run the engine by hand to see its errors:

<engine> -m <models_dir>/<model>.gguf -c 4096
