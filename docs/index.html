AI coding on the PC you already have.

litecode runs open-weight AI models on your own computer. It reads, fixes and reviews code from your terminal. It needs no GPU, no cloud and no API key. It is built for 4-16 GB PCs first.

How it works

It fits the model to the machine

Other tools ask you to pick a model. litecode measures your PC first.

Detect

It reads CPU, cores, RAM, disk type and GPU.

Recommend

It picks models that fit your RAM, with room for your other programs.

Ask

It shows the download size. It downloads only after you agree.

Tune

It measures threads and decoding modes, then keeps the fastest.

Work

It reads, edits and tests code. You approve every change.

Features

A full coding agent, sized for small models

Small models make more mistakes. litecode adds structure so they stay on track: strict tool protocol, grammar-forced output, tests after every change.

01Agent with tools

Read, search, exact-replace edits with a diff preview, run commands, git. Modes: ask, auto, readonly. /undo any edit.

02Memory that grows

Every session is saved to disk. "Always use type hints" is remembered for all projects. Past answers rated /good come back as examples.

03Security review

Static rules find suspects with zero model tokens. The model then gives a 4-line verdict per finding: real or false positive, severity, reason, fix.

04Skills

Save a workflow as a SKILL.md with numbered steps. Run it with /name. Let the model draft one with /skill make.

05MCP client

Connect Model Context Protocol servers. Same .mcp.json format as Claude Code.

06Speed tricks

Prompt cache saved per project. N-gram speculative decoding. One server slot. Quantized KV cache. litecode tune picks by measurement.

07Plain answers

Answers follow ASD-STE100 Simplified Technical English: answer first, short sentences, exact values, no filler. Fewer tokens, faster on slow CPUs.

08Test-fix loop

/test runs your tests. If they fail, litecode reads the error, fixes the code and runs them again.

09Editor autocomplete

litecode fim serves fill-in-the-middle completion. A small VS Code extension is included.

Design principles

Built low-end first

  • 1
    Every byte earns its placeThis page is under 50 KB. litecode has zero Python dependencies.
  • 2
    Numbers, not adjectivesEach claim names the machine it was measured on. Estimates are marked.
  • 3
    Plain wordsShort sentences. One meaning per word. Readable for second-language English speakers.
  • 4
    Works on the worst deviceOffline after setup. Hard drive friendly. No GPU needed.
  • 5
    You stay in controllitecode asks before downloads, edits and commands. Your memory is plain files you can read.
Install

Three commands

Needs Python 3.10 or newer. The setup wizard downloads the engine and the models that fit your PC, after it asks.

Windows · PowerShell
git clone https://github.com/konkomaji/litecode
cd litecode
.\install.ps1
Linux · macOS
git clone https://github.com/konkomaji/litecode
cd litecode
./install.sh

Then: litecode tune once, and litecode in any project folder. Read the full guide.
