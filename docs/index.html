What it does

Built for code and security. Useful for everything else.

The main focus is coding and security review. The same local models also write, explain and analyze, so one tool covers most daily work.

MAINCoding

Fix bugs across files, add features with tests, refactor safely, explain code, write commit messages. /test runs your tests and fixes failures.

MAINSecurity

Static scan with zero model tokens, then a 4-line verdict per finding. SQL injection, XSS, command injection, path traversal, secrets. How it works.

ALSOWriting

Emails, summaries, READMEs, API docs and reports in plain, short sentences that are easy to read in a second language.

ALSOStudy

Ask about concepts, learn a codebase, practice offline. No internet and no data charges after setup.

ALSOData

CSV reports, JSON config edits, log analysis. litecode writes the script and runs it to check the result.

ALSOYour tools

Connect MCP servers and save your own workflows as skills. Same formats as Claude Code. All use cases.

How it works

Five steps, all on your machine

Detect

It reads CPU, RAM, disk type, GPU and VRAM.

Recommend

It picks models that fit, with room for your other programs.

Ask

It shows the download size and downloads only after you agree.

Tune

It measures threads and decoding modes and keeps the fastest.

Work

It reads, edits and tests your code. You approve every change.

Features

A full coding agent that stays on track

Small models make more mistakes, and big models cost time. litecode adds structure to both: a strict tool protocol, grammar-forced output, and tests after every change.

01Agent with tools

Read, search, exact edits with a diff preview, run commands, git. Modes: ask, auto, readonly. /undo any edit.

02Memory that grows

Every session is saved to disk. Your preferences apply to all projects. Rated answers come back as examples. Details.

03Skills

Save a workflow as a SKILL.md. Run it with /name. Let the model draft one with /skill make.

04MCP client

Connect Model Context Protocol servers. Same .mcp.json format as Claude Code.

05Speed on any machine

Prompt cache saved per project, n-gram speculative decoding, GPU offload, and litecode tune to pick by measurement.

06Plain answers

Answers follow ASD-STE100 Simplified Technical English: answer first, short sentences, exact values, no filler.

07Plan mode

/plan inspects without editing and gives numbered steps. You approve, then it runs them.

08Benchmark yourself

litecode eval runs 30 real tasks in 3 levels and scores each model on your machine.

09Editor autocomplete

litecode fim serves fill-in-the-middle completion. A small VS Code extension is included.

Quick answers

Common questions

  • ?
    Can I run an AI coding assistant without a GPU?Yes. litecode runs on CPU only. A 2019 Ryzen 3 with 16 GB RAM generates about 15 tokens per second with the default 2B model.
  • ?
    Does it use my GPU if I have one?Yes. Setup installs the CUDA or Vulkan engine and moves the model to the GPU. With 24 GB of VRAM it runs 30B-class models.
  • ?
    Is my code sent anywhere?No. After setup litecode makes no network calls. Code, prompts and memory stay on your disk as plain files.
  • ?
    Is it only for coding?Coding and security come first. It also writes emails, summaries and docs, answers study questions and handles CSV, JSON and logs.
  • ?
    What does it cost?Nothing. litecode is MIT licensed and the models are open-weight. More answers.
Install

Three commands

Needs Python 3.10 or newer. The setup wizard downloads the engine and the models that fit your machine, after it asks.

Windows · PowerShell
git clone https://github.com/konkomaji/litecode
cd litecode
.\install.ps1
Linux · macOS
git clone https://github.com/konkomaji/litecode
cd litecode
./install.sh

Then run litecode tune once, and litecode in any project folder. Read the Quickstart or the full User guide.
