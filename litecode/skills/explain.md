---
name: explain
description: Explain code to a learner in simple steps.
triggers: explain, understand, what does, how does, teach, learn
tools: read_file, grep
---
1. Read the code the user names. Do not guess its content.
2. Say what it does in one sentence.
3. Walk through it in numbered steps, one idea per step.
4. Name one thing that can go wrong and how to check it.
5. Keep words simple. Define each technical term once.
