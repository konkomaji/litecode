Commands

Shell commands#

CommandWhat it does
litecodeinteractive session in the current folder
litecode "TASK"run one task, then exit
litecode setupwizard: folders, engine, models
litecode tune [ROLE...]measure speed, save best threads and speculative mode
litecode eval [NAME...] [--role R]run 8 real agent challenges and score them
litecode doctorhardware, config, engine, installed models
litecode initcreate LITECODE.md
litecode scan [PATH] [--json]static security scan, no model
litecode review [PATH]scan, then model verdict per finding
litecode plan "TASK"read-only plan
litecode skillslist skills
litecode skills new NAMEcreate a skill step by step
litecode skills rm NAMEdelete a user or project skill
litecode mcplist MCP servers (--tools to list their tools)
litecode mcp add NAME CMD [ARGS...]add an MCP server to the user config
litecode mcp rm NAMEremove it
litecode learn export FILE [--all]write a fine-tune dataset (rated tasks; --all adds unrated)
litecode configshow all settings
litecode config KEY VALUEset one setting (roles.code NAME.gguf for roles)
litecode fimautocomplete server for editors
litecode --versionversion

Flags: --yes (approve all), --readonly, --role NAME, --plan.

Slash commands (in a session)#

CommandWhat it does
/helplist commands
/plan TASKplan with no edits, then ask to run it
/review [PATH]security review
/scan [PATH]static scan only
/test [CMD]run tests; if they fail, fix and run again (max 3 rounds)
/diffgit diff
/commitmodel writes a commit message; you confirm before commit
/model [ROLE]show roles, or force one (auto = router decides)
/mode [ask&#124;auto&#124;readonly]permission mode
/remember TEXTsave a project fact
/prefer TEXTsave a preference for all projects
/memoryshow preferences and facts
/forget [facts&#124;prefs]delete memory (both if no argument)
/good, /badrate the last answer
/undo PATHrestore the newest checkpoint of a file
/sessionslist sessions in this project
/resume [ID]continue a session (latest if no ID)
/clearstart a new session
/initcreate LITECODE.md
/skillslist skills
/skill new NAMEcreate a skill step by step
/skill make DESCRIPTIONmodel drafts a skill; you confirm
/skill rm NAMEdelete a skill
/NAME [TASK]run skill NAME
/mcplist MCP tools
/config [KEY VALUE]show or set config
/costtokens and model time this session
/exitquit (saves cache, extracts facts)
